Innovation Hacks internship — Task 3

A persistent data layer for Users, Projects & Tasks

A relational database, modeled and enforced end to end — connected to the Task 2 API so data survives restarts, deploys, and time. Built with PostgreSQL, Prisma, and Express, live on Vercel.

See the architecture See it verified
~50 seconds

The schema

Four entities, three relationships. Every task belongs to a project and an assignee; every project has members with roles.
